# LAB-evaluation-DSA-Part-B

### Project Overview
This repository contains the practical evaluations for Data Structures and Algorithms (DSA), covering two distinct system implementations.

### Implemented Systems
*   **Part A: Library Management System** — Utilizes structured data arrays and sorting algorithms to organize book inventory efficiently.
*   **Part B: Patient Priority Queue** — Implements a binary max-heap structure to handle emergency room patient triage based on medical severity levels.

### Algorithmic Complexity
*   **Insertion Time Complexity:** O(log n)
*   **Extraction Time Complexity:** O(log n)
